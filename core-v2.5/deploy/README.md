# Artemide deployment options

- **Zero budget, no always-on computer:** See [burst training + browser inference](ZERO-BUDGET-ALTERNATIVE.md) and the Kaggle notebook at `notebooks/artemide-kaggle-free-training.ipynb`.
- **Temporary cloud API prototype:** See [Render Free prototype](RENDER-FREE.md). It may fail due to memory limits and is not a trained assistant.
- **Self-hosted computer:** See the zero-budget [CPU quick start](README.md) when a computer is available.

Do not create paid instances or upgrade plans without explicit approval. A random-initialization checkpoint is only a smoke test; it is not a useful assistant.
